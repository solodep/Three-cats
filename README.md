# Three-cats Events

Учебный сервис регистрации на мероприятия для курса «Разработка безопасного программного обеспечения». Команда — Three-cats.

Организатор публикует мероприятие с ограничением числа мест. Участник записывается и отменяет свою регистрацию. Организатор просматривает список участников своего мероприятия.

## Текущее состояние

Подготовлены черновики паспорта и концепции безопасности для EK1. В коде реализован только минимальный сервер с `GET /health`. Пользовательские сценарии, аутентификация и база данных пока планируются; запуск сервера не подтверждает выполнение требований безопасности.

## Локальный запуск

Нужен .NET 10 SDK. Установщик для Windows, macOS и Linux доступен на [официальной странице .NET](https://dotnet.microsoft.com/download/dotnet/10.0).

Из корня репозитория:

```sh
dotnet restore src/ThreeCats.Events.Api/ThreeCats.Events.Api.csproj
dotnet build src/ThreeCats.Events.Api/ThreeCats.Events.Api.csproj --no-restore
dotnet run --project src/ThreeCats.Events.Api/ThreeCats.Events.Api.csproj --no-build -- --urls http://127.0.0.1:5080
```

В другом терминале:

```sh
curl -i http://127.0.0.1:5080/health
```

Ожидается HTTP `200`, `Content-Type: application/json` и тело:

```json
{"status":"ok","service":"three-cats-events"}
```

Остановить сервер: `Ctrl+C`. Если порт 5080 занят, замените его в обеих командах.

Сервер запускается на локальном адресе. Для этой версии не нужны учётные записи, база данных, внешние сервисы, Docker или секреты.

## Дальнейшая работа

После проверки паспорта и калибровки проекта — хранилище мероприятий, учётные записи и проверка прав, затем регистрация и отмена с контролем числа мест. Проверки из `D-*` выполняются после появления соответствующих механизмов.
